Qu'est-ce qu'Attributor ?

Attributor est une plateforme web scientifique dédiée à l'attribution de formules moléculaires à partir de spectres de masse. Elle associe un moteur de calcul Rust compilé en WebAssembly (Attribrustor), des traitements intensifs exécutés hors du thread principal et une interface scientifique fondée sur un flux de données visuel et interactif. L'analyse s'exécute dans votre navigateur, sans installation : importez vos données, construisez votre traitement et explorez les résultats.

Fonctionnalités principales

⚡ Calculs Rust / WebAssembly

Des noyaux numériques compilés en WebAssembly pour traiter rapidement les données spectrales, directement dans le navigateur.

🧵 Calculs non bloquants

Les opérations lourdes s'exécutent dans des workers dédiés : l'interface reste fluide pendant le calcul, même sur de grands jeux de données.

🧮 Pool de calcul adaptatif

Les tâches sont réparties entre plusieurs workers selon les capacités du navigateur, avec une file d'attente et un repli JavaScript si nécessaire.

🔗 Flux de données interactif

Ajoutez des nœuds, déplacez-les et reliez les étapes de votre analyse. Le flux se lance, se met à jour et visualise clairement la propagation des données.

📈 Visualisation WebGL intégrée

Explorez les spectres XY dans des graphiques interactifs rendus avec WebGL, conçus pour garder une visualisation fluide des données volumineuses.

🔬 Homologie persistante 0D

Un module d'analyse topologique détecte les structures de sous- et super-niveaux et restitue leurs naissances, morts et indices associés.

📂 Import flexible

Chargez des fichiers texte délimités avec séparation et colonnes configurables, ou convertissez vos fichiers bruts .raw via le service msConvert.

💾 Sessions portables

Exportez et importez le flux complet au format JSON, avec versionnage de la session et restauration fidèle des structures de données.

↩️ Expérimentation sans risque

Annulez et rétablissez vos actions grâce à un historique complet, ajustez les paramètres et comparez les résultats de vos scénarios.

Un traitement en pipeline

Fichier brut (.raw) → conversion msConvert → Texte XY → flux de nœuds Attributor → Attribution (Rust/WASM) → Graphiques & export
