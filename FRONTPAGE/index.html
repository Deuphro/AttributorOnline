Qu'est-ce qu'Attributor ?

Attributor est une plateforme web scientifique dédiée à l'attribution de formules moléculaires à partir de spectres de masse (notamment FT-ICR). Elle s'appuie sur un moteur de calcul en Rust compilé en WebAssembly (attribrustor) pour offrir des performances natives, et sur une interface de flux de données entièrement interactive. Vos données sont traitées côté client : rien n'est installé, il suffit d'un navigateur.

Fonctionnalités principales

⚡ Moteur Rust / WebAssembly

Calculs d'attribution ultra-rapides exécutés localement grâce au noyau attribrustor, sans chargement serveur intensif.

🔗 Flux de données interactif

Construisez votre chaîne de traitement en connectant des nœuds : sources de données, opérations, visualisations.

📈 Visualisation intégrée

Tracés XY interactifs (D3.js) pour explorer vos spectres et résultats directement dans l'interface.

📂 Import de données flexible

Chargement de fichiers texte délimités (XY) et conversion des fichiers bruts (.raw) via le service msConvert (Wine/Mono côté serveur).

💾 Sessions sauvegardables

Export et import de vos sessions complètes au format JSON pour reprendre votre travail là où vous l'avez laissé.

↩️ Undo / Redo complet

Historique d'actions avec annulation et rétablissement, intégré à l'interface.

Un traitement en pipeline

Fichier brut (.raw) → conversion msConvert → Texte XY → flux de nœuds Attributor → Attribution (Rust/WASM) → Graphiques & export
